# Landing page media

Drop optional assets here — the landing page degrades gracefully if they are missing:

- `hero.mp4` / `hero.webm` — short (≤8s), muted, looping background video (keep < 4 MB, 1280x720)
- `hero-poster.jpg` — poster frame shown while the video loads
