# Static website starter

A tiny portfolio site: `index.html`, `style.css`, `script.js`.

Preview it on your computer: double-click `index.html`, or run `npx serve .` and open the address it prints.

Deploy it with the AutoDevOps guide "Deploy a static website". Files:

| File | What it is |
|------|-----------|
| `index.html`, `style.css`, `script.js` | The website |
| `Dockerfile` | Optional: run the site in an Nginx container |
| `.github/workflows/deploy.yml` | Optional: auto-deploy on every `git push` |
