# Node.js app starter

```bash
npm install
npm start          # http://localhost:3000
```

Try: `curl http://localhost:3000/health` and `curl "http://localhost:3000/api/hello?name=Asha"`

Deploy it with the AutoDevOps guide "Deploy a Node.js app". Files: `server.js` (the app), `Dockerfile`
(how to package it), `docker-compose.yml` (how to run it), `.github/workflows/deploy.yml` (auto-deploy).
